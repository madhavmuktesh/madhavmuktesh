## 📂 Featured Projects

### 🤖 [Clara AI Pipeline](https://github.com/madhavmuktesh/clara-ai-pipeline)
An automated AI pipeline that converts sales demo transcripts and onboarding audio recordings into fully configured AI voice agent specs for an AI receptionist.
- **Stack:** Python, Groq LLaMA, Groq Whisper, Docker
- **Highlights:** Dual-pipeline (transcript + audio), batch orchestration, Dockerized deployment

---

### 🚁 [Multi-Drone Collision-Free Path Planner](https://github.com/madhavmuktesh/Multi-Drone-Collision-Free-Path-Planner)
Simulates and plans optimal, collision-free 3D flight paths for multiple drones in dense urban environments using real-world Berlin OpenStreetMap data.
- **Stack:** Python, NumPy, GeoPandas, Plotly, Three.js, Jupyter Notebook
- **Highlights:** Quantum-Inspired PSO algorithm, 8 conflict scenarios validated, interactive 3D visualization

---

### 🏥 [HealthCheck AI – Symptom Checker](https://github.com/madhavmuktesh/Healthcare-Symptom-Checker)
A full-stack AI-powered health tool that analyzes symptoms using Google Gemini LLM, with secure user authentication and personalized history tracking.
- **Stack:** React, Vite, Node.js, Express.js, MongoDB Atlas, Google Gemini API, JWT
- **Highlights:** AI symptom analysis, JWT authentication, saved analysis history

---

### 🛒 [BIGZONE – E-Commerce Platform](https://github.com/madhavmuktesh/BIGZONE)
A MERN stack e-commerce application with a full backend and frontend, featuring product browsing, authentication, and order management.
- **Stack:** React (Redux Toolkit), Node.js, Express.js, MongoDB, Google Generative AI
- **Highlights:** Full MERN stack, Redux state management, AI integration

---

### 💬 [Mini-RAG – Question Answering System](https://github.com/madhavmuktesh/Mini-RAG)
A Retrieval-Augmented Generation (RAG) based question answering system that retrieves context and generates accurate answers.
- **Stack:** Python
- **Highlights:** RAG architecture, intelligent document retrieval and answer generation

---

### 🧱 [Predicting Compressive Strength of Concrete](https://github.com/madhavmuktesh/Predicting-Compressive-Strength-Of-Concrete)
A machine learning project that predicts the compressive strength of concrete using regression models, deployed as a Flask web application.
- **Stack:** Python, Jupyter Notebook, Scikit-learn, Flask
- **Highlights:** End-to-end ML pipeline — data collection, preprocessing, model optimization, and deployment

---

### 🤖 [Robo Path Guider](https://github.com/madhavmuktesh/Robo-Path-Guider)
An embedded systems project that controls a robot's movement and navigation using MicroPython, PWM motor drivers, and UART communication.
- **Stack:** MicroPython, UART, PWM
- **Highlights:** Real-time motor control, hardware-level communication

---

### 🅿️ [TRAVEASE – Smart Parking Platform](https://github.com/madhavmuktesh/TRAVEASE)
A web-based platform that connects parking lot owners with users, enabling real-time availability checks and reservations.
- **Stack:** HTML, CSS
- **Highlights:** Clean UI, multi-page navigation, real-time availability design

### 🎓 [Placement Portal](https://github.com/madhavmuktesh/placement_portal)
